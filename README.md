## Требования

- Docker (рекомендуется) — версия `20+`.
- Установленный образ NGINX в Docker через Docker Hub или внутри Docker Desktop (для Windows должен быть установлен WSL 2)
- Если без Docker: любой статический HTTP-сервер (nginx, Apache, Python `http.server`).
- Браузер: Chrome / Firefox / Edge (последние версии).

---

### Сборка образа Docker

```bash
docker build . -t azimut-smolensk
```

---

### Запуск Docker контейнера
```bash
docker run -d -p 8080:80 azimut-smolensk
```
-p - переброс с локального порта Docker образа на хост
-d - запуск контейнера без логов в консоль

---

### Запуск на локальном сервере
(к пр. NGINX) Копируй содержимое проекта в корень `nginx` (например `/usr/share/nginx/html`) или настраивай `root` в конфиге `nginx`:
```nginx
server {
    listen 80;
    server_name example.com;
    root /path/to/project;
    index index.html;
    location / {
        try_files $uri $uri.html $uri/ =404;
    }
}
```

### Инструкция для рядовых пользователей

Инструкция для рядовых пользователей
Навигация

- Главная: `index.html`

- Чтобы открыть раздел: кликни по соответствующей ссылке в верхнем меню.

Скачивание документов

- Открой Документы (Documents).

- Кликни на нужный `PDF` — браузер начнёт загрузку или откроет его в браузере.

- Если загрузка не стартует — правый клик → «Сохранить ссылку как…».

Прсмотр карты

- Кликни в меню на `Карта` и увидешь все инценденты

### Как обновить контент / добавить документ

- скопируй новый PDF в `documents/`
- открой `documents.html` и найди массив с названием `doc_card_container`
- скопируй нужный элемент массива, вставь его, переназови, сохрани.
